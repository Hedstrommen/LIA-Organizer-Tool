# LIA Organizer Tool

Ett enkelt verktyg för att hålla ordning på dina LIA-ansökningar (Lärande i arbete).

## Kom igång via GitHub Pages

1. Gå till repo-inställningarna: **Settings → Pages**
2. Under **Source**, välj `main`-branchen och roten (`/`), spara
3. Efter någon minut finns appen på `https://<ditt-användarnamn>.github.io/LIA-Organizer-Tool/`

## Funktioner

- 📋 **Full översikt**: företagsnamn, ansökningsdatum, sista ansökningsdag, webblänk, ort, LIA-roll och period
- ✅/❌ **Svar från företag**: Ja/Nej + svarsdatum, eller "väntar på svar"
- 👤 **Kontaktperson**: namn, titel, e-post och telefonnummer (klickbar mailto-länk)
- 📝 **Anteckningar** för varje ansökan
- 🔍 **Sökning** över alla fält (företag, kontakt, stad, status m.m.)
- ↕️ **Sortering**: datum (nyast/äldst), företagsnamn A–Ö, eller senast ändrad
- 🏷️ **Filterchips** per status och svar
- 📊 **Statistikpanel**: antal ansökningar, väntande svar, intervjuer, ja och nej
- ⧉ **Duplicera** och ✏️ **redigera** befintliga ansökningar

## Sekretess

All data sparas **endast lokalt i din webbläsare** via `localStorage`. Ingen data skickas till någon server, så flera personer kan använda appen via samma sida utan att se varandras ansökningar. Tänk på:

- Rensar du webbläsardata raderas ansökningarna
- Byter du enhet följer inte datan med automatiskt
